# Hi, I'm Ann

**Excel · XLOOKUP · UNIQUE · Pivot Tables · Slicers · Conditional Formatting · Dashboards**

My background is in manufacturing: I was a production scheduler at one company and worked as the front office coordinator at another. I worked with the same daily reports everyone else got. Excel is where I found the answers. These projects are real work I did for two manufacturers, rebuilt with synthetic data so they can be shared.

## About the data

Every project uses **synthetic data**. Customers, people, part numbers, order numbers and dollar amounts are all invented, and employers are called Manufacturer One and Manufacturer Two. The problems, the processes and the workbooks are how I really did the work.

## Opening the workbooks

Some workbooks use **XLOOKUP** and **UNIQUE**. These need Excel for Microsoft 365, Excel 2021 or later, or the free Excel for the web. Older versions of Excel still show the saved results, but can't recalculate them.
